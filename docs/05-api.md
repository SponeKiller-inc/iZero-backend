# 05 – API

Base prefix: `/api`. The router is composed in [app/infrastructure/api/router.py](../app/infrastructure/api/router.py).

Interactive documentation generated by FastAPI: `/docs` (Swagger UI), `/redoc`, schema at `/openapi.json`.

## Response format

All responses use the `ResponseContainer` envelope ([schemas/base.py](../app/infrastructure/api/schemas/base.py)):

```json
{
  "message_id": 1000001,
  "message": "optional text",
  "data": null
}
```

| Field | Description |
|-------|-------------|
| `message_id` | Numeric message code, see below |
| `message` | Optional accompanying text (not intended for end users) |
| `data` | Endpoint payload, typed via a generic |

## Message IDs

Defined in [schemas/message_id.py](../app/infrastructure/api/schemas/message_id.py). Code format: `EE SS NNN` — 2 digits for the main entity, 2 digits for the sub-entity, 3 digits for the sequence number.

| Code | Constant | Meaning |
|------|----------|---------|
| 1000001 | `USER_NOT_FOUND` | User not found |
| 2000001 | `AUTH_NOT_AUTHENTICATED` | User is not authenticated |
| 2000002 | `AUTH_NOT_AUTHORIZED` | User lacks permission |
| 2000003 | `AUTH_NOT_ACCESS` | Access denied |
| 9000001 | `SYSTEM_INTERNAL_FAIL` | Unexpected server error |

When adding a new code, add a row to this table.

## HTTP status codes

| Code | Usage |
|------|-------|
| 200 / 201 | Success |
| 204 | Success with no body |
| 400 | Invalid input |
| 401 | Missing or invalid authentication |
| 403 | Insufficient permissions |
| 404 | Resource does not exist |
| 422 | Pydantic validation error |
| 500 | Unexpected error (reported to Sentry) |
