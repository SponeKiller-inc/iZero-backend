# Architecture Decision Records

Records of significant architectural decisions. One file per decision, numbered in ascending order.

| # | Decision | Status |
|---|----------|--------|
| [0001](0001-layered-architecture.md) | Layered (clean) architecture | Accepted |

## When to write an ADR

When a decision affects code structure, module boundaries, technology choice, or is hard to reverse.

## Template

```markdown
# NNNN – Title

- **Status:** Proposed | Accepted | Superseded by NNNN
- **Date:** YYYY-MM-DD

## Context
The problem being solved and the constraints that apply.

## Decision
What we chose.

## Alternatives considered
What we rejected and why.

## Consequences
Both positive and negative effects.
```
